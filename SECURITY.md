## Reporting a Vulnerability

If you discover a security vulnerability within the [ads](https://github.com/ANTCPU/ads) repository, please report it directly through responsible disclosure channels. 

* **Where to report:** Open a private security advisory or contact the maintainer team directly via the repository main page.
* **What to expect:** You can expect an initial acknowledgment of your report within 48 hours, along with regular updates on the remediation progress as patches are evaluated and deployed.
