# Contributing to ANTCPU ADS

First off, thanks for taking the time to contribute! 🎉 The ANTCPU ADS framework thrives on community collaboration, open architecture, and shared innovation. 

Whether you're fixing a bug, proposing a new feature, or improving documentation, here is how you can jump in and help build the platform.

## Code of Conduct

By participating in this project, you agree to abide by our community standards. Please keep discussions and contributions constructive, respectful, and focused on pushing the ecosystem forward.

## How Can I Contribute?

### 1. Reporting Bugs
Found an issue with node syncing, backend routing, or ad impression tracking? 
* Open an [issue](https://github.com/ANTCPU/ads/issues) using our issue templates.
* Include clear steps to reproduce the bug, your environment details, and any relevant logs.

### 2. Suggesting Enhancements
Have an idea to optimize the network or add new API endpoints?
* Open an [issue](https://github.com/ANTCPU/ads/issues) to pitch your idea before diving into major code changes so we can align on the roadmap.

### 3. Pull Requests
Ready to submit code? Follow these quick steps:
1. **Fork** the repository and create your feature branch from `main` (e.g., `git checkout -b feature/amazing-feature`).
2. **Commit** your changes with clear, descriptive commit messages.
3. **Push** your branch up to your fork.
4. Open a [Pull Request](https://github.com/ANTCPU/ads/pulls) against the `main` branch with a clear summary of what your changes accomplish.

## Style Guidelines
* Write clean, maintainable code that matches the project's existing architecture.
* Comment complex backend integrations or routing logic where necessary.
* Ensure all tests pass before submitting a pull request.

Thanks for helping us scale the ANTCPU ADS ecosystem! 🚀
